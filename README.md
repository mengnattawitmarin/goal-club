# Goal Club

แอปความน่าจะเป็นคู่ฟุตบอลรายวัน ภาษาไทย ดึงโปรแกรม สกอร์สด ตารางคะแนน และราคาตลาดจาก ESPN ทุกครั้งที่เปิด

## สำหรับนักพัฒนาและ AI ที่เข้ามาช่วย

อ่าน [AGENTS.md](AGENTS.md) ก่อน มีโครงสร้าง โมเดล ข้อมูลในฐานข้อมูล และกติกาที่ห้ามละเมิด
แก้โค้ดที่ `src/` แล้วรัน `npm test` ก่อน push (Vercel build `public/index.html` ให้เองตอน deploy)

## มีอะไรบ้าง

- `src/` ต้นฉบับของแอป (CSS, โมเดล, หน้าจอ) และ `scripts/build.mjs` ประกอบเป็น `public/index.html`
- `api/espn.js` คือตัวกลางดึงข้อมูล ESPN ฝั่งเซิร์ฟเวอร์ แคชสกอร์ 30 วินาที ตารางคะแนน 30 นาที
- `api/brief.js` อ่านหัวข่าว BBC Sport, The Guardian, ESPN แล้วให้ Claude เขียนบทวิเคราะห์ (ต้องมีคีย์)
- `public/manifest.webmanifest`, `public/sw.js` และไอคอน สำหรับติดตั้งลงหน้าจอโฮม

## ขึ้นเว็บด้วย Vercel (ฟรี)

1. อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ขึ้นรีโป GitHub `goal-club` (หน้า Add file → Upload files แล้วลากทั้งโฟลเดอร์)
2. เข้า vercel.com → Add New → Project → เลือกรีโป `goal-club` → Framework Preset เลือก Other → Deploy
3. (ถ้าต้องการบทวิเคราะห์จากข่าว) Settings → Environment Variables เพิ่ม `ANTHROPIC_API_KEY` แล้ว Redeploy

เสร็จแล้วจะได้ลิงก์ เช่น `goal-club.vercel.app` เปิดบนมือถือแล้วกดเพิ่มลงหน้าจอโฮม

## ข้อมูลร่วมทุกเครื่อง (แนะนำ)

ฟันธง ผลงานย้อนหลัง บทวิเคราะห์ และสิ่งที่โมเดลเรียนรู้จากผลจริง จะใช้ชุดเดียวกันทุกเครื่องเมื่อต่อฐานข้อมูล Upstash Redis

1. Vercel → โปรเจกต์ goal-club → แท็บ Storage → Create Database → เลือก Upstash for Redis (แพ็กเกจฟรี)
2. ตั้งชื่ออะไรก็ได้ เลือก Region ใกล้ไทย (เช่น Singapore) → Create → Connect to Project → goal-club
3. Vercel ใส่ตัวแปร KV_REST_API_URL และ KV_REST_API_TOKEN ให้อัตโนมัติ → ไปที่ Deployments แล้ว Redeploy

ถ้ายังไม่ต่อ แอปยังใช้ได้ปกติ แต่ข้อมูลจะเก็บแยกในแต่ละเครื่อง

## การอัปเดต

- เปิดแอปแล้วดึงข้อมูลสดทันที เก็บไว้ในเครื่องเพื่อเปิดครั้งต่อไปได้เร็ว
- ระหว่างมีคู่แข่งหรือใกล้เตะ อัปเดตเองทุก 1 นาที นอกนั้นทุก 10 นาที และทุกครั้งที่กลับมาเปิดแอป
- ถ้าฟีดล่ม แอปยังเปิดได้ด้วยข้อมูลที่ดึงไว้ล่าสุด
